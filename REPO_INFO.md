Fitness Tracker Site (Workout Quest) — Static website

Overview

This repository contains the static marketing/landing website for the Fitness Tracker (Pocket Coach / Workout Quest). Built with Astro + Tailwind.

Key locations
- Repo root: /projects/fitness-tracker-site
- Source: src/
- Public assets: public/

Quick commands
- Install deps: yarn install (or npm install)
- Run dev server: yarn dev
- Build static site: yarn build
- Preview production build: yarn preview

Notes
- Uses Astro and TailwindCSS.
- Vercel deployment configured (vercel.json present).
- yarn.lock present; uses Yarn by default.

Testing & linting
- ESLint configured; run yarn lint
